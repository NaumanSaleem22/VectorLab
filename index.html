      Features

      Built for real vector work

      Genuine tracing

      Powered by VTracer, compiled to WebAssembly. Output is paths and Bézier curves, never an embedded bitmap.

      Full colour or binary

      Hierarchical colour clustering for artwork and photos, binary tracing for line art and scans.

      Side-by-side compare

      Synchronised zoom and pan, plus a slider to reveal the original under the vector.

      SVGO optimization

      Every result is also optimized with SVGO, with both file sizes shown so you can choose.

      Validated output

      Each SVG is checked for valid XML, a viewBox, real geometry and no embedded images or scripts.

      Private by design

      No accounts, no uploads, no tracking. Conversion runs in a Web Worker on your own machine.

      About

      An honest vectorizer

      VectorLab traces images with VTracer, an open-source raster-to-vector engine by visioncortex, running as WebAssembly inside your browser. Files are optimized with SVGO.

      Good to know

      • Logos, icons and flat illustrations give the cleanest, smallest results.
      • Photographs do convert, but become thousands of shapes. Expect large files and a stylised, posterised look rather than photographic fidelity.
      • Very large images are scaled down before tracing to keep memory use safe. The SVG keeps the original dimensions.
